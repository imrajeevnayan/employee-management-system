How to Run the Employee Management System

Clone the GitHub repository and start the application using Docker Compose. 

git clone https://github.com/imrajeevnayan/employee-management-system.git

cd employee-management-system

docker compose up --build

# Open:
# http://localhost:8080

Run Without Docker 

mvn spring-boot:run

Run Tests 

mvn verify

FAQ — Employee Management System

What is an Employee Management System?

An Employee Management System is software used to manage employee records, departments, user accounts, roles and other human resource management activities.

How do I run this Spring Boot Employee Management System?

Clone the GitHub repository, enter the employee-management-system directory and run docker compose up --build. Then open http://localhost:8080.

What technologies are used in this project?

The project uses Java, Spring Boot, Spring MVC, Thymeleaf, Spring Security, Spring Data JPA, PostgreSQL, Flyway, Bootstrap, Docker and JUnit.

How is role-based access control implemented?

Spring Security is used to implement authentication and authorization. Access can be controlled using URL rules, method-level security and application service rules.

Which database does the project use?

The Employee Management System uses PostgreSQL for persistent application data and Flyway for database migrations.

Is the Employee Management System open source?

Yes. The source code is available on GitHub: Employee Management System GitHub Repository .
