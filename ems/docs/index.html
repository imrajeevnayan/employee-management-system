FAQ — Employee Management System in Spring Boot

How do I run this Spring Boot employee management system?

Run docker compose up --build in the ems folder, then open http://localhost:8080 and sign in with admin / Admin@123. The database, schema and demo data are provisioned automatically.

What are the default login credentials?

Four seeded accounts — admin / Admin@123, hr.kavya / Hr@12345, mgr.arjun / Manager@123, emp.priya / Employee@123 — one per role. The admin password can be overridden before first boot via EMS_ADMIN_PASSWORD.

How is role-based access control implemented in Spring Security?

Three enforcement layers: URL rules in SecurityConfig, @PreAuthorize on mutating methods, and service checks such as assertCanManage which restricts managers to their own department.

Which database does it use — can I use MySQL or H2?

PostgreSQL 16 via Flyway with ddl-auto: validate. The automated test suite already runs on H2 in PostgreSQL mode; swapping to MySQL only requires changing the JDBC URL/driver and adjusting the migration dialect.

How are passwords stored?

As BCrypt hashes via Spring Security’s PasswordEncoder, with an 8–64 character strength policy (upper, lower, digit, special) enforced on create, reset and change flows.

Does the project include tests?

Yes — 27 tests covering the RBAC matrix, the login flow, Thymeleaf page rendering, service business rules, repositories and Flyway schema validation. Run them with mvn verify; no external database needed.
